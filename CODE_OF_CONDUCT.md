# Code of conduct

The WAFio project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
It applies in every repository of the Wafio organisation on GitHub, in issues, pull requests, discussions and reviews,
and wherever someone represents the project.

In short: be respectful, assume good intent, criticise the work and not the person, and accept that the maintainers
decide what is merged.

## Reporting

Report behaviour that breaks this code to <hello@wafio.cloud> with "Conduct" in the subject. Only the maintainers
read that address. We keep reports confidential, and we reply to every one.

## Enforcement

The maintainers decide what happens after a report, following the enforcement guidelines of the Contributor
Covenant: a private correction, a warning, a temporary ban or a permanent ban. A maintainer who is part of a report
takes no part in deciding it.
